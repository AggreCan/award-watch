Award Watch: three identity directions

The same three pages in three visual identities, built from real CanadaBuys records of 2026-10-31, so the comparison is about design and not content. Each page has a Dark or Light button in its header; the choice is kept in this browser and carries across all nine pages. The FR button does nothing here. README.md in this folder has the reasoning, the costs and the figures behind the profile page.

One mark for all three: lowercase "aw" in Inter Bold, the second v of the w a check in emerald #0f7b4f. Every masthead carries brand/mark-two-tone.svg inline, beside the name set in that direction's own type; the tab icon is brand/favicon.svg. The wordmark (brand/wordmark.svg, right) is not used on the pages, since beside the mark it would repeat "aw". The check fixed the accent, so all three directions use the same emerald and differ in ground, type and layout.
